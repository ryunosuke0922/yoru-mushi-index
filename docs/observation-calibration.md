# Observation Calibration

実観測に基づいて夜虫指数を調整するための方針です。

## 目的

スコアの重みを実観測ログと照合して調整するための計画です。記録の収集・保存機能や学習済みモデルは、まだ実装していません。
特定地点、街灯、採集地、生息地、希少種のリアルタイム位置を扱わず、粗いエリア単位の傾向だけを利用します。

現行の `heuristic-v0.2` は未校正です。入力の修正を完了したことと、観察に対する予測精度を改善したことを分けて評価します。

## 収集候補

| 項目     | 記録する内容                                                                         |
| :------- | :----------------------------------------------------------------------------------- |
| 観察状態 | 実施 / 未実施。実施して0匹だった場合と未実施を区別                                   |
| 結果     | 分類群別の数、または事前に定義した多い / 普通 / 少ない / 0                           |
| 分類     | 蛾 / 甲虫 / 水辺の羽虫 / その他。希少種や細かな種名を収集しない                      |
| 観察努力 | 開始時刻、継続時間、観察人数。比較時には方法と時間を揃える                           |
| 方法     | 目視 / 灯火など。灯火なら光源の種類・出力の区分。設置場所は記録しない                |
| 環境     | 住宅地 / 林縁 / 水辺 / 山地などの区分                                                |
| エリア   | 公開済みの粗い `areaId` のみ                                                         |
| 予測     | 観察前に提示した指数、時間帯、公開可能な気象・月条件、利用可能性、モデル版、計算日時 |

観察努力と非検出を記録する理由は [GBIF の調査データ公開ガイド](https://docs.gbif.org/guide-publishing-survey-data/en/) に従います。任意投稿のない日を0匹と見なさず、観察方法の異なる結果を無条件に合算しません。

## 比較手順

1. 予測対象を決める。例は「一定時間・一定方法での分類群別の多寡」。灯火への集まり方と一般的な飛翔活動を同じ正解データにしない。
2. 観察前に出した予報と入力を固定して保存する。`generatedAt` は計算時刻であり気象モデルの発表時刻ではない。発表時刻が取得できるデータでは別途保持する。
3. 月・地方・環境・分類群・観察方法ごとの誤差と標本数を確認する。欠測・取得失敗は生物の0匹とは別集計にする。
4. 過去期間で調整し、その後の期間を検証用に残す。未知エリアへの妥当性はエリア単位の除外検証も行う。同じ夜の複数時間を学習用と検証用へ無作為に分割しない。
5. 旧版、新版、気温だけの簡単な基準を同じデータで比較する。多寡なら順序の誤りと分類ごとの混同行列、数なら観察努力を揃えた誤差を使い、標本数とばらつきも示す。
6. 特定の観察結果の確率を出す場合は、その事象の定義と確率校正を別に検証する。点数の置き換えだけで百分率にしない。

正確な観察地点を保存しないため、地点固有の影響を完全に分離できない制約があります。地域内のばらつきとして明示し、詳細地点を後から収集して埋め合わせません。

## 次に調整する候補

- エリア別の平年気温による季節係数と月初の不連続、地方・分類群別の季節性。
- 日没からの経過時間。現行の19-23時という固定範囲との比較。
- 20-24℃帯の上限、湿度の単調な加点、月明かりと観察方法の関係。
- 雨・風上限と直近雨量の加点。近い閾値に変えて結果が不安定にならないか確認する。
- サンプル数が少ないエリアでは個別補正せず、全国または地方単位の傾向として扱う。

これらは検証候補であり、収集前に改善率や必要標本数を断定しません（[open-questions.md](open-questions.md)）。

## 外部データの扱い

[静岡県の予察灯資料](https://www.pref.shizuoka.jp/_res/projects/default_project/_page_/001/061/175/08edashakunagacha202610.pdf) のような半旬合計と平年値は季節性の参考にします。5日前後の合計を日ごとの値へ分割して、夜ごとの雨・風との教師データにしません。予察灯とフェロモントラップ、対象分類群、集計期間を区別します。

気象と観測の関係を調べる過去天候と、実際にその時点で出ていた予報の検証も別です。[Historical Forecast](https://open-meteo.com/en/docs/historical-forecast-api) はrun初期部分をつないだ時系列であり、当時の昼に見た夜の予報をそのまま再現しません。[Previous Runs](https://open-meteo.com/en/docs/previous-runs-api) / [Single Runs](https://open-meteo.com/en/docs/single-runs-api) または保存した入力を用いて、実運用と同じ予報先時間で比較します。

## 禁止事項

- exact latitude / longitude を保存しない。
- 街灯、林道、橋、公園内の具体地点を保存しない。
- 希少種のリアルタイム出現情報を保存・公開しない。
- 観察ログから具体的な採集地を推定できる表示をしない。
