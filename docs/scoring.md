# Scoring

夜虫指数は、夜間に飛翔する昆虫の観察しやすさを 0-100 で表すルールベースの指数です。

現行モデルは `heuristic-v0.2`、校正状態は `uncalibrated` です。数値は観測から推定した出現確率ではありません。今回の変更は入力の誤りと過大な表示を抑えるためのもので、実観測上の予測精度の向上を確認したものではありません。研究で確認された関係と未検証の仮定は [research-evidence.md](research-evidence.md) に分けて記録します。

## 入力

- 気温
- 湿度
- 降水量
- 風速
- 突風
- 雲量
- 月照度、月高度、雲量による月明かりの見え方
- エリア別・月別の季節係数
- エリア別の季節スコア
- 生息環境スコア
- 観察時間帯の開始時刻までの直近24時間雨量。24時間分が揃わなければその時間帯を算出しない。

観察時間帯は19:00-20:00から23:00-翌00:00です。気温等の瞬時値は開始時刻、降水量と突風はその区間の集計値を用います。日時・欠測の処理は [data-sources.md](data-sources.md) に従います。必要な気象条件のない時間帯にはスコアを付けません。

## 総合スコア

`packages/core/src/score.ts` の `calculateNightInsectScore()` で算出します。

初期値は `35` です。そこに気温、風、雨、湿度、月明かり、季節、広域環境を加点・減点します。

基本方針:

- 暖かい時間帯を加点
- 低温時は最終スコアに上限をかける
- 湿度が高い時間帯を加点
- 弱風を加点
- 強風、突風、観察時間中の降水を減点
- 観察区間の降水量が0.5mm未満の場合、直近24時間雨量に応じて加点
- 月が高く明るく、雲量が少ない場合は減点
- エリア別の季節スコアを加点
- エリア別・月別の季節係数を最終スコア全体に掛け、時期による活動量の差を反映
- 生息環境スコアを加点

実装上の主な閾値:

以下の配点、気温上限、エリア別の平年気温による季節係数は既存の仮置きを維持しています。普遍的な昆虫の生理的閾値として扱いません。地域・分類群・観察方法ごとの妥当性は未検証です（Q-07〜Q-11）。

```txt
気温:
  26℃以上  +18
  24℃以上  +12
  22℃以上   +6
  20℃以上    0
  18℃以上   -8
  16℃以上  -16
  12℃以上  -28
  12℃未満  -40

気温による最終上限:
  25℃未満は 18-25℃ の範囲で滑らかに補間
  24℃  最大86
  23℃  最大78
  22℃  最大70
  21℃  最大62
  20℃  最大55
  18℃  最大45
  18℃未満  最大45
  16℃未満  最大30
  12℃未満  最大15

湿度:
  80%以上  +8
  65%以上  +5
  50%以上   0
  50%未満  -6

風:
  風速 2m/s 以下 かつ 突風 4m/s 以下   +12
  風速 4m/s 以下 かつ 突風 7m/s 以下    +4
  風速 6m/s 以下 かつ 突風 10m/s 以下  -10
  それ以上                                  -20

雨:
  観察時間帯の降水量 2mm 以上   -18
  観察時間帯の降水量 0.5mm 以上  -8
  直近 24 時間雨量 5mm 以上      +9
  直近 24 時間雨量 1mm 以上      +4

月明かり:
  見える月明かり 0.75 以上  -14
  見える月明かり 0.45 以上   -8
  見える月明かり 0.2 以上    -3
  それ未満                    +5

エリア別の季節適性:
  seasonScore * 15

地域・月別の季節補正（気温による上限の適用前）:
  平年値が5℃以下で係数0.05、22℃以上で1。
  その間は直線補間し、係数を小数第2位に丸める。
  score *= season.factor

広域環境:
  habitatScore * 10
```

日別・週間ともに、各予報日の日本時間の月を使います。帯とスコア理由は同じ係数の区分を参照します。0.20以下は「かなり低い」、0.55未満は「低い」、0.85未満は「中程度」、それ以上は「高い」です。これらは広域の気候から作る暫定的なルールで、種ごとの活動限界を表しません。

## 雨・風による上限

暖かさや湿度の加点で降水・風の減点が相殺され、悪条件でも高い指数になることを抑えます。既存の雨・風の区切りを使い、総合スコアと分類別スコアの両方に次の上限を適用します。

| 条件（いずれか）                                        | 最終上限 |
| :------------------------------------------------------ | :------- |
| 観察区間の降水量が2mm以上、風速が6m/s超、突風が10m/s超  | 29       |
| 観察区間の降水量が0.5mm以上、風速が4m/s超、突風が7m/s超 | 49       |

両方に該当する場合は低い上限を使います。これは未校正モデルの保守的な表示規約であり、論文が「2mmなら29点」「6m/sなら飛べない」と示したものではありません。観察データでの妥当性と閾値の感度分析を残す方針です（Q-11）。

## ラベル

`packages/core/src/labels.ts` の `scoreLabel()` で表示ラベルを返します。

```txt
85-100  とても高い
70-84   高い
50-69   普通
30-49   低い
0-29    とても低い
```

確率の校正を行っていないため、UI に百分率の見込みを表示しません。API の互換フィールド `probabilityBand` は常に `null` です。スコアが80でも「80%の確率で見つかる」という意味にはなりません。

## 分類別スコア

`calculateTaxaScores()` で総合スコアに分類群ごとの補正を加えます。

分類別スコアは、総合スコアを土台にして分類群ごとの感度差を出すための表示用スコアです。総合スコアには既に気温、雨量、生息環境が含まれているため、分類別補正は意図的な追加補正です。

```ts
moths = totalScore + habitatScore * 8;

beetles = totalScore - 12 + temperatureScore(temperature) * 0.4;

aquaticInsects =
  totalScore - 4 + Math.min(recentRainMm24h, 12) * 1.2 + habitatScore * 4;
```

上式の値は丸めと範囲制限、気温・雨・風の上限適用前です。分類別にも総合と同じ気温上限を適用し、追加加点で上限を超えないようにします。直近24時間雨量が不明な時間帯の分類別スコアは算出しません。

補足:

- 蛾: 生息環境スコアを総合より少し強めに反映します。総合スコア側の `habitatScore * 10` に加えて、分類別で `habitatScore * 8` を追加します。
- 甲虫: 総合スコアから `12` 点下げ、気温スコアの `40%` を戻します。現行の `temperatureScore()` では 26℃以上は `18` 点です。
- 水辺の羽虫: 総合スコアから `4` 点下げ、直近 24 時間雨量を最大 12mm まで `1mm = 1.2 点` として加点し、生息環境スコアも追加します。

例:

雨・風の上限が発動しない場合の例です。

```txt
totalScore = 70
habitatScore = 0.8
temperatureScore(26℃) = 18
recentRainMm24h = 8

蛾:
70 + 0.8 * 8 = 76.4 → 76

甲虫:
70 - 12 + 18 * 0.4 = 65.2 → 65

水辺の羽虫:
70 - 4 + 8 * 1.2 + 0.8 * 4 = 78.8 → 79
```

この方式は実装が単純で、総合スコアとの関係が読みやすい一方、総合スコアに含まれる要素を分類別で再加点する面があります。将来的に精度を上げる場合は、総合スコアの内訳と分類別固有スコアを分ける余地があります。
